Minecraft整合包《末日：幸存者》仓库

## 📖 关于
一款基于 Minecraft 的硬核末日剧情生存整合包。

## 💻 运行配置要求
* **游戏版本**：Minecraft 1.20.1
* **Mod 加载器**：Forge 47.4.23
* **推荐内存**：6GB 及以上
* **Java 版本**：Java 17
